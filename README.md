# Mohammad and Hadeel — Wedding site

## Deploy (GitHub Pages)
index.html at the root of this folder is the whole website — self-contained, no other files needed.
1. Upload index.html to the repository root.
2. Settings > Pages > Branch: main, folder: / (root) > Save.

## Files
- index.html — the live website (all photos, fonts and the logo are embedded)
- source/Wedding.dc.html — editable source of the site
- source/Invitation.dc.html — editable source of the Arabic invitation card
- source/support.js — runtime needed by the two source files
- source/assets/ — original photos, logo, and invitation-ar.png (the invitation image)
